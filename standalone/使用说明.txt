LogiG304 0.1.0-preview.1 — 独立离线 G304/G305 控制器

支持 Windows 10/11 x64，需 .NET Framework 4.8（Windows 10 1903 及之后通常已包含）。
使用 Windows 自带 HID 驱动，不需要安装 G HUB，不包含罗技程序、驱动或任何个人配置。
整个软件没有联网、更新、遥测、登录功能。也不需要通过防火墙实现离线。

安装：双击 LogiG304-Setup.exe，选择有写入权限的空文件夹。
便携：解压 ZIP，在任意有读取/执行权限的普通本地文件夹双击 LogiG304.exe。
移动：关闭软件，再移动整个文件夹。没有固定 C 盘入口。
卸载：关闭软件并删除这个文件夹，没有服务、任务或注册表清理步骤。
不自动保存配置，不读取 G HUB 的数据库。所有当前值从鼠标读取。

功能：读取型号、电量估值、DPI、回报率、控制模式；在设备支持时调整当前
DPI、当前回报率，显式切换软件/板载模式，选择已有板载 DPI 档位。
每次写入都需要点击按钮并确认，随后会回读验证。
鼠标休眠时请移动唤醒后刷新。暂只允许连接一个 G304/G305 原装接收器。

检测到 G HUB、Logitech Gaming Software 或 Onboard Memory Manager 运行时，
阻止写入；可自行退出它们后刷新。本程序不会停止、卸载或修改这些软件。
再次运行 G HUB 后，它可能重新应用自己的设置。本程序不会改 G HUB 配置文件。

预览版限制：已在一只 G304 上实际验证只读通信。为保护现有用户设置，
本版写入路径只有模拟设备回归验证，尚未完成真实设备写入验收。
软件模式设置不保证断电保存。本版不编辑板载配置、不写设备闪存/固件，
不支持重映射按键、宏、游戏自动切换或完整 G HUB 功能。
模式切换会影响鼠标使用哪个现有配置，可能立即改变 DPI/按键行为。
不应将本预览版描述为已经完整替代 G HUB 或兼容所有固件的稳定版本。

本版未做代码签名。请仅从项目 Releases 下载，并核对 SHA256SUMS.txt。
