LogiG304 standalone references the HID++ 2.0 protocol documentation at:
https://github.com/Logitech/cpg-docs/tree/master/hidpp20

Feature command numbers, DPI range encoding, report interval bit masks and
onboard profile header fields were implemented with reference to libratbag's
src/hidpp20.c and src/hidpp20.h. No Logitech binary or resource is included.
https://github.com/libratbag/libratbag
