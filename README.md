# LogiG304

Windows 上面向罗技 **G304** 的本地离线安装与启动工具。支持自选安装盘和子目录，日常从安装目录里的 `G HUB Offline.exe` 启动。

本项目复用固定版本的官方 G HUB 核心，不是从零实现的鼠标控制器，也不是免安装便携软件。程序与日常配置保存在所选目录，Windows 仍需登记服务、驱动、兼容入口和防火墙规则。

## 下载状态

**本仓库公开自有工具源码，目前没有公开分发含罗技核心的完整安装包。** GitHub 的 “Download ZIP”、源码构建产物 `Setup.Development.exe` 和旧独立控制器预览版都不是完整安装包。

通用包构建流程排除个人配置，保留官方核心、运行库、G304/G305 资源和所需虚拟 HID 驱动，不要求目标电脑预装 G HUB。含官方资源的完整包仍须另行满足[罗技软件许可](https://www.logi.com/en-ie/tos/software-license-agreement)；AGPL 不授予官方资源再分发权。

下文供已合法取得完整通用包的用户参考。无网络、未预装 G HUB 或罗技驱动的 Windows Sandbox 已通过驱动安装、服务登记和首次界面初始化。仍未完成全新物理电脑连接 G304 的验收，详见 [安装验证记录](docs/VALIDATION.md)。

## 普通用户如何安装

### 安装前

- Windows x64、.NET Framework 4.8、本机 NTFS 磁盘，目标盘至少有 4 GB 空间。准备好完整包后，安装无需联网。
- 接好 G304 接收器，打开鼠标电源。
- 不能与另一份 G HUB 同时安装。安装器发现已有服务会停止，不覆盖正在使用的客户端。迁移前先备份自己的设置。
- 保持 Windows 防火墙启用，不需要关闭杀毒软件。

### 安装步骤

1. 解压完整包，保留 `GHub-Local-Setup.exe` 和旁边的 `.exe.config`。
2. **普通双击**安装器，不要预先选择“以管理员身份运行”。
3. “存放位置（上级目录）”可填 `D:\Software\Mouse Tools`，“软件文件夹”填 `GHub`。实际安装位置会显示为 `D:\Software\Mouse Tools\GHub`，不限于盘符根目录。
4. 新用户把“旧本地版配置来源”留空。只有主动迁移自己以前的本工具安装时才填写旧安装根目录。
5. 点击“安装并验证”，确认 Windows 管理员提示。安装器解包、安装随包驱动、登记服务和离线规则，并检查界面就绪状态。

通用包不含作者的数据库、账号、个人宏、分组或历史日志；目标电脑首次运行时生成自己的配置。只有显示安装完成后才能视为此次软件安装成功。首次启动可能显示官方欢迎和诊断/隐私选项，请自行完成；离线使用不需要登录。安装就绪事件不等于已经识别到鼠标。

### 日常使用

- 双击安装目录中的 **`G HUB Offline.exe`**，或安装器创建的快捷方式。入口是原生 EXE，不通过 VBS 或 `wscript.exe` 启动。
- 进入 G304 页面设置 DPI、回报率和按钮分配。离线模式无法使用账号同步、社区下载等云端功能。
- 默认离线。需要主动允许联网时，打开同目录的 `网络设置.exe` 切换并授权；自动更新仍关闭。
- 安装后不要叠装另一份官方客户端。不要直接移动或改名安装目录；换电脑需要重新安装。

## 为什么 C 盘也有 LGHUB？

例如实际安装位置为 `D:\Software\Mouse Tools\GHub`：

| 位置 | 内容 |
| --- | --- |
| 安装目录下 `App` | 官方核心的实际文件 |
| 安装目录下 `Data\Profile` | 当前用户的配置与界面数据 |
| 安装目录下 `Data\System` | 机器资源与驱动安装资源 |
| `C:\Program Files\LGHUB` | 指向上述 `App` 的目录联接，兼容核心使用的固定路径 |
| AppData / ProgramData 的 LGHUB 入口 | 指向安装目录相应数据子目录的联接 |

C 盘入口通常不是第二份重复安装；通过它看到的文件实际位于所选目录。Windows 驱动仍安装到系统 DriverStore 等位置，安装恢复记录也由系统管理。

**目录权限：** 系统服务的程序及必要上级目录需要防止普通进程替换，因此目录本身改名、移动或删除可能要求管理员权限；上级目录内其他软件和普通文件保留原有读写权限。这不是加密。若不希望常用共享目录受到这类保护，可选专用父目录，例如 `D:\G304Apps\GHub`。

## 备份、卸载和报错

- 备份：正常退出 G HUB 后，备份安装目录中的 `Data\Profile`。不要公开上传 `Data`、`Backups` 或日志。
- 卸载：普通双击 `卸载 G HUB 本地版.exe` 并按提示授权；它解除本工具的服务、入口和规则，保留配置及可能被其他软件共用的驱动。
- 失败：保留错误摘要、安装器旁的 `last-setup.json` 和目标目录 `Data\Control`，不要手动删除目录联接或反复改权限。
- 提示重启时，保存工作并重启目标电脑后再恢复或重试。不要跳过资源校验。
- 提交问题前去除用户名、SID 和私人路径，不上传数据库、密钥或完整日志目录。
