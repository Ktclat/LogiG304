# 辅助工具包使用说明

此 ZIP 提供本项目已经编译好的自有辅助工具，适用于 Windows x64 和 .NET Framework 4.8。它不是完整安装包，也不是独立的 G304 驱动程序。

## 下载后先看这里

1. 将 ZIP 解压到普通文件夹，阅读本说明。解压不需要管理员权限，也不会更改现有 G HUB。
2. 如果电脑上尚未安装本项目配套的本地版，请不要直接运行 `tools/` 内的程序。这个下载包缺少官方核心、驱动和 G304 资源，不能完成首次安装；普通官方 G HUB 的安装也不能直接与这些工具混用。
3. 如果你已在使用可用的本地版，请继续使用原安装目录中的入口。此 ZIP 不是自动升级包，不要覆盖现有文件或配置。
4. 开发者可以在自己的构建流程中使用这些辅助程序，配合另行有权使用的固定版本资源，按照对应源码中的 `docs/BUILD.md` 生成完整安装包并另行验证。不要通过替换正在使用的版本来测试。

## 文件用途

| 文件 | 用途 |
| --- | --- |
| `tools/G HUB Offline.exe` | 已正确部署的本地版日常启动入口 |
| `tools/网络设置.exe` | 配套本地版的离线/联网设置入口 |
| `tools/卸载 G HUB 本地版.exe` | 配套本地版的卸载入口，仅在有有效安装记录时使用 |
| `tools/*.exe.config` | 对应程序的运行配置，需与 EXE 放在一起 |
| `LogiG304-Source.zip` | 本次构建完整对应源码，包含构建、补丁、测试与安装脚本 |
| `package-manifest.json` | 提交版本、文件校验值及包的能力边界 |
| `LICENSE`、`NOTICE.md`、`THIRD_PARTY.md` | 自有代码与第三方组件许可说明 |

配套官方核心版本固定为 `2025.9.814156`。ZIP 中不包含官方核心、官方驱动、设备资源、私人配置、测试入口或无资源安装器。程序没有商业代码签名，不需要为解压而关闭 Windows 安全功能。

## 校验下载

发布页中的 `SHA256SUMS.txt` 列出两个 ZIP 的 SHA-256。可在 PowerShell 中对下载的 ZIP 执行 `Get-FileHash .\LogiG304-Tools-Windows-x64.zip -Algorithm SHA256`，与同名条目逐字比较。摘要用于检查下载完整性，不能替代来源可信性判断。

## 构建与发布维护

仓库每次推送 main 和拉取请求都会编译、测试并产生辅助工具下载。Actions 下载保留 30 天，通常需要登录 GitHub。维护者可在 `Build and downloads` 中使用 `Run workflow`，在 `main` 分支勾选 `publish_release`，通过全部检查后自动创建公开下载页。

发布页下载不依赖临时 Actions 产物的保留期。每个源码提交只发布一次；重复发布同一提交会停止，不会覆盖已经发布的文件。来自拉取请求或其他分支的构建不能执行发布步骤。

本地维护者在干净、已提交的源码目录运行 `./scripts/build.ps1 -Test -Package`，可生成同样结构的下载包。需要 Git 和 Python 3；输出目录 `artifacts/downloads/` 必须尚不存在。打包仅使用明确列出的自有程序，以及当前提交的源码归档，不会将本机 `artifacts/` 整个上传。
