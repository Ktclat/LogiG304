# 发布前审核记录

日期：2026-10-25。范围：本仓库自有源码、构建路径、个人信息边界和本机清理。
这是一轮人工结合自动测试的代码审核，不是对罗技闭源核心的完整安全审计。

## 修复并保留的关键行为

| 项目 | 处理与验证 |
| --- | --- |
| 驱动异步安装误判 | 等待连续稳定快照；模拟延迟、缺失、替换间隙、读错误与超时 |
| ACL 回退顺序 | 用实际 NTFS 测试复现先恢复子目录的错误，再验证父目录优先的回退 |
| 等效 ACE 比较 | 测试合并/拆分与通用权限位，拒绝新增权限、deny 和传播范围变化 |
| 安装通信文件竞争 | 共享读取、原子替换、有限重试；并发进度读写回归 |
| 路径与联接 | 阻止路径穿越、设备名、越界删除和不匹配联接；仅处理已记录的路径 |
| 失败重试 | 仅接受受保护记录中的已完成回退条件；保留原文件，不覆盖数据 |
| 离线规则 | 限定程序清单，验证规则完整属性；不修改无关程序或全局策略 |
| 私人修复器 | 排除绑定单个电脑 SID、事务编号及固定路径的历史一次性修复器 |
| 公开数据 | 不提交官方核心、ASAR、驱动、截图、用户数据库、机器记录或安装日志 |
| 开发构建误用 | 无资源时在打开安装窗口前停止；不会先修改目录再发现资源缺失 |

## 验证层次

原私人完整包曾通过 129 项安装器回归、34 项启动器回归和 2162 个资源文件完整校验；用户随后确认 G304 设备页面正常。
公开源码排除了 7 项与一次性私人修复器绑定的测试，并调整了文件系统测试以使用当前存在的磁盘。
源码构建、前端模拟测试与公开文件扫描由 CI 重新运行。当前测试结果以 CI 日志为准。

公开源码与已经安装的私人包不是逐字节相同的制品：公开代码去掉私人修复入口、允许无个人配置的种子布局，并阻止无资源开发构建误启动。
这些修改没有部署到已经安装的客户端。
