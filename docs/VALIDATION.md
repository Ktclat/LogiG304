## 隔离安装

Windows Sandbox：Windows 11 x64（22000）、.NET Framework 4.8、无网络适配器、关闭剪贴板共享。初始系统未预装 G HUB 或罗技驱动。仅映射测试工具及专用结果目录，不映射现用安装或个人配置。

测试入口使用实际安装源码和相同完整资源清单；仅允许在 Sandbox 专用账户和测试目录下运行。管理员阶段执行安装事务，普通权限令牌执行正式启动器，保留界面就绪检查。这不是普通用户点击安装器的完整 UI 自动化验收。

最终测试通过：实际安装并运行三个所需驱动 `logi_joy_vir_hid`、`logi_joy_bus_enum`、`logi_joy_xlcore`；服务、离线规则和目录入口建立成功；生成新的用户数据库；安装事务返回 `success: true, phase: complete`。

正式启动器返回 0，在约 5.8 秒报告界面初始化完成，前端自身约 2.1 秒。只读画面检查确认显示官方首次使用的诊断/隐私选择页。这只是本次隔离环境的测量，不是启动速度承诺，也**不是已连接 G304 的设备页**。

日志中的历史名称 `device-ui-ready` 对应官方 `ON_APP_LOADED` 事件；它不证明已发现鼠标，也不证明用户已经完成首次欢迎页。普通用户首次安装仍需自行完成这些页面。

早期失败来自测试工具创建的普通权限令牌：其访问控制导致 Chromium 无法创建子进程令牌（错误 49）。修正测试令牌自身的对象权限和默认 DACL 后，同一资源包通过；没有修改正式程序的安全检查、关闭 Chromium 沙盒或更改宿主系统安全设置。

## 实体 G304

旧私人包曾在原用户电脑 D 盘子目录安装成功，用户确认设备页面与配置正常。这不能证明无个人配置通用包已在全新物理电脑验收。

Sandbox 没有连接实体 G304 接收器；本次不声称实测了全新系统上的 DPI 写入、按钮、回报率及板载存储。仍需在断网的完整 Windows 测试电脑上连接 G304，完成安装、重启后打开、设置及卸载检查。
