首个不依赖 G HUB 核心的独立 Windows G304/G305 控制器预览版，采用 MIT 许可证。

- 通过 Windows 自带 HID 直接访问接收器，无官方程序、驱动包、个人配置或网络功能。
- 可选择空文件夹安装，也可用 ZIP 解压运行；没有 C 盘兼容联接、服务或目录权限修改。
- 读取型号、电量估值、当前 DPI、回报率及控制模式。
- 实现当前 DPI/回报率调整、模式切换及已有板载 DPI 档位选择；只有点击并确认才写入，随后回读。
- G HUB 等罗技控制程序运行时，禁止设置写入，保留只读查看。

**验证边界：** 一只 G304 的真实只读通信通过，62 项模拟协议、安装、资源和界面检查通过。为保留原用户正在使用的 G HUB 和配置，没有在该鼠标上试写。实际写入及无 G HUB 的全新系统尚待验收，因此这是预览版，不是完整 G HUB 替代品。

不支持修改板载配置、持久化 DPI 档位、按键重映射、宏或游戏自动切换。软件模式设置不保证断电保存；模式切换可能立即改变 DPI 和按键行为。不写闪存或固件。

下载 `LogiG304-Setup.exe` 安装，或解压 `LogiG304-0.1.0-preview.1-win-x64.zip`。要求 Windows 10/11 x64、.NET Framework 4.8、一个 G304/G305 原装 USB 接收器。使用自己有写入权限的新文件夹，不覆盖已有 G HUB。

发行包未做代码签名。可使用附带的 `SHA256SUMS.txt` 核对文件。程序不会要求关闭杀毒软件。
