# 旧的官方核心封装方案（历史说明）

此文件只记录旧方案。当前独立控制器见 [项目首页](../README.md)。

面向 Windows 上罗技 G304 的本地控制与离线运行工具源码。

**当前公开的是自有工具源码，不是可直接下载安装的完整 G HUB 替代客户端。**
仓库没有罗技核心、驱动二进制、设备资源或任何用户配置。MIT 许可证只适用于本仓库的自有代码。

## 已验证的实现

2026-10-25，一个包含用户自有官方资源的私人安装包已在一台 Windows 电脑上完成安装，用户确认进入 G304 设备页面。
它支持自选本机 NTFS 子目录，程序和配置的实际文件位于安装目录，日常通过该目录中的原生 EXE 启动。
公开源码基于该实现整理；私人安装包不在此仓库或 Releases 中分发。

- 默认阻止外部网络访问，保留设备控制所需的本机通信。
- 使用 Windows 防火墙约束核心进程；Electron 层阻止外部请求与浏览器跳转。
- 提供离线/允许联网切换，保留关闭自动更新的设置。
- 记录安装事务、备份权限，并在失败时恢复入口、规则和权限。
- 等待 Windows 完成驱动配置，避免官方安装进程刚退出就误报失败。
- 支持对已记录的驱动阶段失败保留全部文件后重试。
- 提供解除安装入口，保留配置文件和共享驱动。

## 构建和测试自有代码

要求 Windows x64、.NET Framework 4.8、PowerShell，以及用于前端测试的 Node.js。
构建使用系统中的 .NET Framework 编译器，不下载 NuGet 包，也不要求联网。

```powershell
./scripts/build.ps1 -Test
node ./frontend/test-offline.cjs
python -m unittest discover -s tests -p "test_*.py"
python ./scripts/audit_public.py
```

输出在忽略提交的 `artifacts/` 中。测试只在测试目录内创建文件和联接，不安装驱动、不修改防火墙，也不启停现有 G HUB。
默认生成的 `Setup.Development.exe` 没有官方资源；直接打开会提示缺少资源，不能把它当成完整安装包。
详见 [构建说明](BUILD.md) 与 [代码审核记录](REVIEW.md)。

## 范围与限制

- 仅在一台电脑、一个 G304 上实际验证过。未验证所有 G304 固件、Windows 版本或其他罗技设备。
- 核心版本固定为 `2025.9.814156`。文件哈希不匹配会停止操作。
- 不是免安装便携软件。Windows 服务、驱动、C 盘兼容目录联接和少量受保护的恢复记录仍然存在。
- 安装在其他盘时，服务程序所在目录及必要的上级目录需要防替换权限；目录改名、移动可能要求管理员权限。
- 离线模式依赖 Windows 防火墙保持启用，不能使用云端登录、社区内容等网络功能。
- 未对整个闭源核心做安全审计；本仓库的防火墙和请求限制不等于通用安全沙箱。
- 不承诺任意路径移动、多人同时使用、与另一份官方客户端共存或无需重装就跨电脑使用。
